# 도구 정의서 — FABOT 투자 신호·잔고 안내 챗봇

(design-packet.md의 ②번 항목과 동일한 내용을 도구별로 독립 문서화한 것입니다.)

## get_fg_signal

- **한 문장**: 오늘 날짜의 F&G 지수와 그에 따른 매매 신호(매수/매도/커버드콜/대기)를 조회한다.
- **쓰는 때**: "오늘 신호가 뭐야", "F&G 몇이야", "지금 매수 타이밍이야?"
- **안 쓰는 때**: 특정 종목의 쿨다운만 궁금할 때, 과거 날짜의 신호를 물을 때
- **인자**: 없음 (항상 오늘 기준)
- **반환**: `{date, fg_score, rating, signal_label, is_stale}`
- **실패 시**: 1회 재시도 → 실패하면 캐시값을 `is_stale: true`로 반환

## check_cooldown

- **한 문장**: 지정한 종목이 매수 쿨다운 상태인지 조회한다.
- **쓰는 때**: "TQQQ 지금 사도 돼?", "쿨다운 언제 풀려?"
- **안 쓰는 때**: 종목 미지정 일반 시장 질문
- **인자**: `ticker`(필수) — 누락 시 호출하지 않고 되묻는다
- **반환**: `{ticker, in_cooldown, last_buy_date, elapsed_trading_days, reason}`
- **실패 시**: 1회 재시도 → 실패하면 "확인 불가, 매수 전 직접 확인 권장"

## get_balance

- **한 문장**: 계좌의 현재 보유 종목과 평가손익을 조회한다.
- **쓰는 때**: "지금 계좌 얼마야", "수익률 어때"
- **안 쓰는 때**: 기간별 추이를 물을 때(→ get_balance_history)
- **인자**: `broker`(필수, "KIS"|"Kiwoom") — 누락 시 되묻는다
- **반환**: `{broker, holdings: [{ticker, name, quantity, avg_price, current_price, pl_amount, pl_rate}]}` — 계좌번호·API 키 절대 미포함
- **실패 시**: 1회 재시도 → 실패하면 "잔고 조회 일시 실패"

## get_balance_history

- **한 문장**: 최근 N일간의 일별 수익률 추이를 조회한다.
- **쓰는 때**: "요즘 수익률 어떻게 변했어"
- **안 쓰는 때**: 지금 이 순간의 잔고만 궁금할 때(→ get_balance)
- **인자**: `broker`(필수), `days`(선택, 기본 7, 최대 90)
- **반환**: `{broker, records: [{date, profit_rate, profit_amount}]}`
- **실패 시**: 있는 데이터만 반환, 전체 실패면 "이력 조회 실패"

## search_strategy_rule (RAG/임베딩 기반)

- **한 문장**: FABOT 매매 규칙(CLAUDE.md) 중 질문과 의미상 가장 관련 있는 규칙을 찾아 반환한다.
- **구현 방식**: 규칙 5개를 조각(chunk)으로 나눠 fastembed(`BAAI/bge-small-en-v1.5`)로 임베딩,
  Qdrant 인메모리 벡터DB에 저장. 질문도 같은 방식으로 임베딩해서 코사인 유사도로 top-2 검색.
  실행 코드: `my-agent/rag_strategy_search.py`
- **쓰는 때**: "커버드콜은 언제 사?", "TQQQ 매도 조건이 뭐야?"
- **안 쓰는 때**: 실시간 F&G 점수처럼 지금 값이 필요할 때(→ get_fg_signal)
- **인자**: `query`(필수) — 자연어 질문
- **반환**: `[{text, score}]` — top-2 이상 (top-1만 쓰지 않는 이유는 아래 실측 참고)
- **실패 시**: 상위 점수가 낮으면(0.5 미만) "관련 규칙을 찾지 못했습니다"

**실측(2026-08-27)에서 발견한 한계** — `traces/trace-04-rag.txt`에 원문 전체 보존:
1. 영어 전용 임베딩 모델이라 한국어 문장에서 진짜 정답 규칙이 1등이 아니라 2등으로 나옴
   → top-1이 아니라 top-2 이상 반환하도록 설계 변경
2. 소형 로컬 모델(0.8b)이 도구 결과를 종합해 답을 만드는 데 실패(빈 응답)
   → 최종 답변은 검색된 규칙 원문을 그대로 인용하도록 설계(요약·숫자변형 금지)
